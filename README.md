# 🌦️ Weather App

A Python desktop weather application that retrieves weather information from a weather API and displays it through a Tkinter GUI.

## Status

🚧 Under Development

## Planned Features

- Search weather by city
- Current temperature
- Weather condition
- Humidity
- Wind speed
- Atmospheric pressure
- Visibility
- Sunrise and sunset
- Error handling
- Weather API integration
- Windows executable

## Technologies

- Python
- Tkinter
- REST API
- JSON
- Git & GitHub
